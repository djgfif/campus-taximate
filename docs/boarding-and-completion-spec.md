# S45: 탑승 인증과 운행·정산 완료

2026-11-19 승인한 추가 명세. 탑승번호는 **팀원 제안**이다. 기존 S31·S32·S35를 대체하지 않고 탑승 증거와 운행 시작 조건을 보완한다. S44는 기존 도보 경로 결정에 사용되므로 재사용하지 않는다.

## 시각과 상태

| 행동 | 의미 |
|---|---|
| 도착 표시 | 승차 장소에 도착했거나 곧 도착함. 탑승 증거와 구분 |
| 현재 결제자의 실제 탑승 표시 | 본인 탑승 기록, 6자리 번호 공개, 인증 마감 설정 |
| 동승자 번호 입력 | 해당 발급 세대의 번호가 맞고 기한 이내이면 본인 탑승 인증 |
| 현재 결제자의 운행 시작 | 명시적 출발. 도착·스케줄러·승계 수락·영수증 제출은 이를 대신하지 않음 |
| 인증 마감 | 실제 탑승 표시 +5분. 예정 T+5분 운행 확인과 별개 |
| 정산 확정 | 인증 기한 및 필요한 조사·이의 처리가 종료된 뒤 결제·환불 진행 |

예약 선결제/무료 취소 마감은 T−20분, 즉시는 확정+5분이다. 모의 지급 장부에는 실제 송금이 없다.

## 번호와 승계

- 번호는 발급 세대별 고정 6자리 문자열로 앞자리 0을 보존한다.
- 잘못된 입력은 사용자별·세대별 최대 5회이며, 요청 실패나 동시 요청 때문에 횟수가 유실되지 않는다.
- 성공한 입력의 재전송은 같은 성공 결과로 처리하고 추가 실패로 세지 않는다. 기한·세대·소속·권한은 서버에서 검사한다.
- 원문 번호는 현재 결제자만 조회한다. 다른 일행 조회, 채팅, 실시간 신호, 알림, 로그에는 포함하지 않는다.
- 결제자 승계 시 기존 번호는 무효가 된다. 이미 인증된 사람의 기록은 보존한다. 새 결제자가 실제 탑승을 표시하면 새 세대와 5분 기한을 연다.
- 운행 시작 시 아직 열려 있는 입력 기한을 조기 종료하지 않는다. 입력 기한 중 미인증자를 즉시 제외하거나 노쇼로 확정하지 않는다.

## 미확인과 조사

- 번호 미입력/입력 잠김은 조사 후보이며 노쇼 확정과 구분한다.
- 본인은 번호 미수령, 입력 잠김, 그 밖의 사유를 기존 24시간 소명 절차로 제출한다. 동승자의 출석 확인과 영수증·채팅을 함께 검토한다.
- 운행 확인 자료가 있고 기존 소명 기한 동안 반대 증거나 소명이 없는 경우에만 기존 자동 판정 조건을 적용한다.
- 증거가 충돌하거나 결제자의 번호 전달 여부를 판단할 수 없으면 관리자 심사로 보낸다. 판단 불가는 S35의 노쇼 면책을 적용한다.
- 기존 복수 노쇼 보전 한도, 결제자 승계 거부, 운행 미확인 종료 규칙을 보존한다.
- 실제 탑승이나 긍정적인 운행 답변이 있는데 출발 표시만 누락된 경우, 24시간 경과만으로 미운행·환불을 확정하지 않고 관리자 검토로 보낸다. 번호를 열고 출발하지 않은 파티도 무기한 READY로 남기지 않는다.
- 관리자 운행 판정은 `OPERATED` 또는 `NOT_OPERATED`와 근거를 명시한다. 영수증 부재로 미운행을 추정하지 않는다. 운행 인정 시 기존 시작 기록을 보존하거나 관리자 복구임을 감사 기록에 남기고 영수증 입력을 재개한다. 입력하지 않은 탑승번호 인증을 만들어 내지 않는다.

## 완료와 재현성

- 확정적으로 거절된 과거 승인 시도는 이후 재결제 성공을 영구 차단하지 않는다. 진행 중 승인·필요한 환불·관리자 확인은 계속 완료 조건에 포함한다.
- 인원 축소 때 원래 출발지와 고정된 예약 시각을 이용하여 최초와 동일한 지연·절약 조건을 재검증한다. 확정 당시 금융 조건은 보전 계산을 위해 보존한다.
- 무료 이탈 재검증에서 경로 조회가 실패하면 조건을 통과한 파티로 진행하지 않는다. 재시도 가능한 보류를 유지하고 출발을 막으며, 마감 전에 접수된 무료 이탈의 권리를 재시도 시각 때문에 잃지 않게 한다.
- 영수증 삭제·수정·관리자 판정은 파티 단위 잠금으로 조정하며 7일 보관 규칙을 유지한다. 증거가 없으면 그 사실을 표시한다.
- 적용한 V1~V15를 변경하지 않는다. 추가 스키마는 V16 이후로 적용하고 기존 DB 이력이 다른 경우 별도 이관한다.
