# MVP 요구사항 요약 (제출용)

> **기준일:** 2026-11-27 · **상세 명세:** [functional-requirements.md](functional-requirements.md) (FR 40개, 테스트 기준·NFR 포함) · **기준 흐름:** 후불 정산 v3
>
> 팀 초안(FR 20개)의 형식을 유지하면서 내용을 현재 구현에 맞춘 요약본이다. 원본 양식에 섹션 2가 있다면 별도로 채운다.

## 1. MVP 핵심 기능 우선순위 (P0 / P1 / P2)

- **P0 (필수 기능):** 회원가입 및 학교 인증, 결제수단 등록, 탑승 조건 입력 및 예상 요금 확인, 자동 매칭 및 일행 확정, 탑승 인증(탑승번호) 및 결제자 승계, 실제 택시비 입력, 분담금 계산 및 후불 결제, 정산 이의 제기, 노쇼 처리, 관리자 심사
- **P1 (중요 기능):** 모집 중인 일행 합류, 그룹 채팅 및 알림, 신고 및 재매칭 차단, 결제·이용 내역 조회, 관리자 운영 관리(이용 제한·미정산·승차 지점·감사 기록)
- **P2 (확장 기능):** 일행원 칭찬, 누적 절약액 요약, 예상 요금 정확도 분석, 추가 사용자 편의 기능

## 3. 기능적 요구사항 (Functional Requirements)

### 회원 및 계정

- **FR-01. 회원가입 및 학교 인증 (P0):** 학교 이메일 코드 인증 후 비밀번호·별명·성별을 등록해 가입하는 기능 (성별은 동성 매칭에 사용)
- **FR-02. 로그인 및 계정 관리 (P0):** 로그인, 로그아웃(모든 기기 포함), 비밀번호 재설정, 학과·입학 연도 공개 여부 설정 기능
- **FR-03. 결제수단 등록 및 관리 (P0):** 탑승 요청 전 후불 결제에 쓸 결제수단을 등록·변경하는 기능 (미등록 시 요청 불가)

### 탑승 요청 및 매칭

- **FR-04. 탑승 조건 입력 (P0):** 공통 승차 지점(도보 10분 이내), 목적지(검색·지도), 출발 시각 또는 도착 기준 시각을 입력하는 기능
- **FR-05. 예상 요금 확인 (P0):** 요청 전 혼자 탈 때의 예상 택시비와 도보 시간을 확인하는 기능
- **FR-06. 탑승 요청 (P0):** 입력한 조건으로 자동 매칭을 요청하는 기능 (결제수단 미등록·미납·진행 중 요청이 있으면 거절)
- **FR-07. 자동 매칭 및 일행 확정 (P0):** 같은 승차 지점·동성이고, 같이 가서 늘어나는 시간 15분 이내, 예상 요금 기준 10% 이상 절약되는 요청을 2~4명 일행으로 자동 확정하는 기능
- **FR-08. 매칭 결과 및 일행 정보 조회 (P0):** 매칭 대기·확정·미성사 상태와 확정 일행의 하차 순서·결제자·개인별 예상 분담금을 확인하는 기능 (타인 상세 주소 비공개)
- **FR-09. 요청 취소 및 인원 변경 대응 (P0):** 매칭 전 요청 취소, 매칭 후 무료 취소 기한 내 탑승 취소, 인원 변경 시 계속 탈지 빠질지 선택하는 기능 (한 명만 남으면 해산)
- **FR-10. 모집 중인 일행 합류 (P1):** 조건이 맞는 기존 일행을 조회하고, 경로·시간·절약 조건과 차단 여부를 재검증한 뒤 합류하는 기능

### 탑승 및 소통

- **FR-11. 도착 및 운행 시작 표시 (P0):** 승차 지점 도착을 일행에게 알리고, 결제자가 운행 시작을 표시하는 기능 (미표시 시 일행원에게 탑승 여부 확인)
- **FR-12. 탑승번호 인증 (P0):** 결제자가 6자리 탑승번호를 발급하고, 동승자가 5분 안에 입력해 실제 탑승을 인증하는 기능
- **FR-13. 결제자 승계 (P0):** 결제자가 이탈하면 다음 하차 순서 동승자가 결제자 역할을 수락·거절하는 기능 (승계 시 이전 탑승번호 즉시 무효)
- **FR-14. 그룹 채팅 및 진행 알림 (P1):** 일행 확정 시 전용 채팅방(텍스트·사진·읽음 표시)을 제공하고, 매칭·탑승·정산 단계별 알림(메일·웹 푸시)을 보내는 기능
- **FR-15. 신고 및 재매칭 차단 (P1):** 부적절한 동승자를 신고하거나 다시 매칭되지 않도록 차단하는 기능

### 정산 및 이용 관리

- **FR-16. 실제 택시비 입력 (P0):** 운행 종료 후 결제자가 실제 택시비와 영수증 사진을 등록하고, 정산 확정 전까지 수정하는 기능
- **FR-17. 분담금 계산 (P0):** 실제 택시비를 각자 혼자 탈 때의 예상 요금 비율로 나누어 개인별 분담금을 계산하는 기능 (분담금 합계 = 실제 택시비)
- **FR-18. 정산 확인 및 후불 결제 (P0):** 동승자가 영수증과 분담금을 확인하고 등록 결제수단으로 1회 결제하는 기능 (전원 확인 시 즉시, 무응답 시 6시간 뒤 자동 확정)
- **FR-19. 정산 이의 제기 (P0):** 실제 택시비나 영수증에 문제가 있을 때 6시간 안에 이의를 제기하는 기능 (접수 시 자동 확정 중단, 관리자 심사로 전환)
- **FR-20. 탑승 미확인 및 노쇼 처리 (P0):** 일행원이 미탑승을 표시하면 당사자가 24시간 안에 소명하고 관리자가 판정하는 기능 (탑승번호 미입력만으로 노쇼 확정 금지)
- **FR-21. 결제 및 이용 내역 조회 (P1):** 진행 중·완료 이용 내역, 정산 결과, 결제·미납 내역과 결제자의 수령 예정액을 조회하는 기능

### 관리자

- **FR-22. 관리자 심사 (P0):** 노쇼, 요금 이의, 운행 여부를 근거와 함께 판정하는 기능
- **FR-23. 관리자 운영 관리 (P1):** 회원 이용 제한 적용·해제, 미정산 현황 처리, 승차 지점 등록·수정, 처리 기록(감사 이력) 조회 기능
- **FR-24. 부가 기능 (P2):** 일행원 칭찬, 누적 절약액 요약, 관리자용 예상 요금 정확도 조회 기능

## 4. 앱 한 줄 소개

캠퍼스 택시메이트는 같은 방향으로 이동하는 대학생을 자동으로 매칭해, 실제 택시비를 이동 거리 비율대로 공정하게 나누고 탑승번호 인증으로 안전한 동승을 돕는 서비스이다.
