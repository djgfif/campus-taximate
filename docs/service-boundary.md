# 모의 운영 범위와 확인할 운영 요건

확인일 2026-11-19. 교수 피드백의 법적 위험 검토를 위한 발표 근거다. 이 프로젝트에 대한 관할기관의 허가나 유권해석을 확보한 것은 아니다.

## 확인한 공식 자료

[국토교통부, 2022-06-14 정책 설명](https://www.korea.kr/news/policyNewsView.do?newsId=148902516)은 플랫폼 합승의 승객 신청·본인 확인, 상대방 탑승 정보, 좌석 안내, 차종별 성별 조건, 긴급신고 기능과 사업자의 면허·등록 절차를 설명한다. 이는 해당 발표 당시 제도 설명이며, 일반 대학생 앱에 대한 포괄적 허가로 해석하지 않는다. 기사 사진은 사용하지 않는다.

[국가법령정보센터 제16조](https://www.law.go.kr/법령/택시운송사업의발전에관한법률/제16조) 링크도 확인했지만 이 실행 환경에서는 본문이 추출되지 않았다. 따라서 2026-11-19 현재 법령 전문·시행규칙·개별 앱 적용 여부까지 확인했다고 표시하지 않는다.

## 현재 구현의 범위

- 학교 계정으로 모의 사용자를 구분하고, 공통 승차 지점 매칭·채팅·인증번호·비율 정산을 시연한다.
- 토스 모의 결제 또는 별도 확보된 테스트 키를 사용한다. 결제자에게 지급할 금액은 모의 장부에 남기며 실제 송금하지 않는다.
- 일반 택시 호출, 기사와의 경유 협의, 실제 운송과 지급대행 계약을 앱이 완료한 것으로 표현하지 않는다.
- 학교 이메일이나 탑승번호가 법령상 요구되는 본인 확인·안전 요건을 충족한다고 단정하지 않는다.

## 실제 운영으로 전환할 때 남는 확인

앱의 매칭 방식이 어떤 운송 중개 유형에 해당하는지, 필요한 등록·면허와 운송사업자 협의, 승객 보호·긴급신고, 결제·지급 계약, 개인정보 처리, 지도·경로 API 저장·이용 조건을 해당 기관·계약 상대와 확인해야 한다. 이 항목들은 현재 모의 캡스톤의 완료 조건과 실제 운영 허가를 구분하기 위한 것이다.

## 발표 문장

“이번 프로젝트는 매칭과 정산 절차를 구현하고 모의 환경에서 검증한 캡스톤입니다. 실제 송금은 하지 않습니다. 플랫폼 합승에 적용되는 안전 기준과 사업자 요건이 있으므로, 실제 운영 가능성은 관할기관 확인과 별도 계약이 필요합니다.”
