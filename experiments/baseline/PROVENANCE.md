# 모의실험 입력 출처와 재사용 범위

현재 matching-engine·서버의 매칭/검증/정산/보전 코드를 직접 재컴파일한다. 기존 taximate-matching-sim/realdata에서 가져오는 것은 121개 목적지 후보(허브 포함), Kakao 단독 견적·구간 행렬·사례·TIMS 연간 격자 캐시뿐이다. 이전 알고리즘 구현은 가져오지 않는다. 원본은 읽기 전용이며 복사본과 생성 입력은 experiments/.cache에 둔다. 과거 Kakao 호출은 1,490회로 기록하고 이번 신규 호출은 0회로 구분한다. 과거 요금 MAPE는 견적 보정 모델의 차이이며 실제 미터 결제 오차가 아니다.

C5는 한국교통안전공단 TIMS 2025 격자별 영업통계(500m×월, data.go.kr 15165682)만 비교한다. 전국/통학권과 행정구역 매핑된 포천 캐시 격자를 분리한다. 월별 잔차는 평균 운행거리·시간의 포천 낮 요금 근사와 관측 평균 요금의 차이다. 통학권 선택에 쓰인 연간 격자는 월별 자료로 오인하지 않는다. C6/C7은 이 잔차의 평균을 유지한 편차 1.0/1.5/2.0배를 사용한다.

C7은 서울시·KT OA-22300 2026년 10월 포천 출발 귀가 목적의 지역/시간 비중을 사용한다. 서울도 자치구로 합쳐 모든 지역의 커버리지 단위를 시군구로 통일한다. 각 지역 흐름 중 캐시 점이 있는 유일 TIMS 격자 승차량/지역 전체 TIMS 격자 승차량만 남기고 나머지를 유실로 센다. 남긴 흐름은 격자 승차량으로 분할한다. 허브와 단독 캐시 없는 2개 점은 목적지 추출에서 제외하여 118개만 사용한다. 지역 누락·포천 내부 이동·0흐름 지역과 지점별 최종 확률을 JSON에 공개한다. OA-22299는 목적 구분 없는 2030 비율 기술통계만 제공한다. 출처: 서울특별시·KT, 서울시 통신데이터.

공식 서울 파일 서버에 multipart POST로 내려받은 ZIP은 캐시에만 두며 공개 산출물에는 집계와 날짜·크기·SHA256·URL만 남긴다. 공휴일 10/5·10/9를 제외한 20개 월~금 날짜를 집계하고 10/31 토요일은 제외한다. 10/5 대체공휴일 ZIP은 해시 manifest에 제외 사유를 남기고 분석에서는 뺀다. 시간 코드는 H/HH와 HHMM을 구분해 시 단위로 합치며 cnt=*는 결측 제외한다. 마스킹 셀을 0으로 대체하지 않는다.

## 한계

- 실제 합승 성과 미검증. 모의 일수·요청·정산 반복을 관측 학생 이용량으로 세지 않는다.
- 생활이동은 통신 기반 추정치이며 포천은 시군구 단위라 캠퍼스 단위가 아니다.
- 귀가 목적이 학생 하교를 대표한다는 가정. 2030 비율은 학생 비율도 귀가 연령 비율도 아니다.
- TIMS 잔차는 집계 평균이라 개별 오차를 과소추정한다. 비선형 평균·요금 지역 혼합·미터 clock 부재 편향이 있다.
- 캐시 행렬 약 51.5%가 관측 구간 합성이며 시간대 교통 변동을 재현하지 않는다. 기본 하루 100건·참여율 50/100/150%는 가정이다.
- C6의 비양수 일행-반복 제외와 C7의 양수 조건부 잔차 추출은 서로 다른 조건부 분모다. 노쇼 보전 전액 회수와 승계 수락을 가정한다.

재현 명령과 산출물 설명은 ../README.md, 실행 입력·생산 코드 해시는 ../reports/의 JSON을 따른다.


지역 전체 TIMS 분모는 tims_regions.py가 공식 SGIS 2025Q2 시군구 경계(data.go.kr 15129688)에 TIMS 500m 격자 중심점을 공간 결합해 만든다. EPSG:5179 UTM-K 중심점 계산식·공식 PRJ의 투영 파라미터·경계 밖 격자 수와 영업건수·원본 해시는 reports/tims-region-MANIFEST.json에 있다. 최근접 지점의 지역을 이식하지 않는다. SGIS 코드와 행정안전부 코드의 연결은 시도명+시군구명 유일 일치로 검증한다.

포천 사용점 4개는 모두 소흘읍이므로 포천 전체 시내 흐름을 대표하지 않는다. 공간 커버리지 보정 후에도 TIMS 밀도가 귀가 밀도를 대신한다는 가정과 격자 중심점의 경계 배정 한계가 남는다. 포천 내부 이동 제외 민감도를 기본 조건 옆에 보고한다. 이 조건은 100요청/일과 시간 분포를 고정하고 목적지만 재정규화한다. 출처: 국가데이터처(통계청) SGIS, 2025년 2분기 센서스용 행정구역 경계.
