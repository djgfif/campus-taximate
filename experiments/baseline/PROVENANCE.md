# 기존 실험의 재사용 범위

원본 프로젝트: `taximate-matching-sim/realdata`.

재사용하는 것은 한국 요청 입력(`data/korea_cases.txt`), 도로 구간 캐시(`data/kakao_matrix.tsv`), 과거 자료의 한계 설명이다. 앱 저장소 외부에 있는 원본은 읽기 전용으로 취급한다. 실행 시 선택된 입력과 행렬을 로컬 비공개 캐시에 복사하고 원본과 선택 자료의 SHA-256을 보고서에 남긴다.

기존 `src/Core.java`의 현재 엔진 호출과 단독 요금 가중치 비교 방식을 참고해 앱 저장소의 독립 CLI 어댑터를 작성했다. 선택·검증·분담금 알고리즘은 옮겨 적지 않고 현재 앱의 실제 소스를 직접 컴파일한다. 과거 `javacD.args`의 다른 체크아웃 절대 경로나 `RealProbe` 스텁, DP 대안 구현은 사용하지 않는다.

자료 성격:

- 국내 118개 대표 지점은 실제 학생의 승하차 기록이 아니다.
- TIMS 수요는 택시 승차 집계에서 가져온 대리 자료다. 일부 요청 시각은 가상이다.
- 구간 행렬은 관측 구간과 합성 구간이 섞여 있다. 기존 요약 기준 합성 비율은 약 51.5%다.
- 다중 경유 요금 모델과 카카오 견적의 차이는 실제 미터 결제액 정확도를 나타내지 않는다.
- 과거 1,490회 호출과 이번 오프라인 실행의 신규 0회 호출을 구분한다.
- 기존 모델의 높은 최적 대비 성능이나 NYC 결과를 현재 앱의 실제 서비스 검증으로 옮겨 주장하지 않는다.

현재 생성 결과는 `reports/korea-cached.*`를 확인한다. 과거 보고서 숫자를 그대로 복사한 결과물이 아니다. 현재 매칭 소스·실행 입력·설정이 달라지면 결과도 달라질 수 있다.
